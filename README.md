AI Dungeons and Dragons Character Creator
This project is AI powered, easy way to create a character.  The application generates your character, including back story and plot hooks, spell lists and basic equipment.

It is set up similar to an app call DnD Beyond.  User choose their race, Class, and Level.  For those not into dnd or similar your race is if you are humen, or elf, or something else.  Class is weather you are a fighter, wizard, or theif.  Those are just some basic ideas.
You can choose to set your own stats, strength, dex ect.  Or let the AI take the wheel and set them for you.  It uses the DND 5e, or most current rules for stats.
You also have the option to pick a name, or to have the AI find one for you.
Once these are done, then it will generate your character, have a basic picture of your character, and background of said character.  

This can then  be exported into a character sheet. 

To enhance immersion, the interface was redesigned into a polished fantasy-themed layout using custom CSS, animated backgrounds, card-based UI components, and styled stat blocks resembling real tabletop character sheets. A PDF export system was implemented using ReportLab, allowing players to download and print their characters in a professional format.

Overall this project shows some ways in which you can use AI and other tools to create your ideas and make them real.
